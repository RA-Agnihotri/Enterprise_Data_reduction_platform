## 2. Metadata Schema & Table Creation

### 2.1 Create EDRP_METADATA Schema

```sql
CREATE SCHEMA IF NOT EXISTS DATA_REDUCTION_POC.EDRP_METADATA 
COMMENT = 'Enterprise Data Reduction Platform - Metadata and Configuration';
```

### 2.2 TABLE_INVENTORY — Master table list with reduction strategy

```sql
CREATE TABLE DATA_REDUCTION_POC.EDRP_METADATA.TABLE_INVENTORY (
    TABLE_ID          NUMBER AUTOINCREMENT PRIMARY KEY,
    SOURCE_DATABASE   VARCHAR(256)  NOT NULL,
    SOURCE_SCHEMA     VARCHAR(256)  NOT NULL,
    TABLE_NAME        VARCHAR(256)  NOT NULL,
    TABLE_TYPE        VARCHAR(50)   NOT NULL DEFAULT 'UNKNOWN',  -- DIMENSION, FACT, BRIDGE, REFERENCE, HIERARCHY
    TABLE_ROLE        VARCHAR(50)   NOT NULL DEFAULT 'UNKNOWN',  -- ROOT, INTERMEDIATE, LEAF
    ROW_COUNT         NUMBER,
    SIZE_BYTES        NUMBER,
    PRIMARY_KEY_COLS  VARCHAR(1000),    -- Comma-separated PK column names
    REDUCTION_STRATEGY VARCHAR(50) DEFAULT 'SAMPLE',  -- FULL_COPY, SAMPLE, FK_CASCADE, EXCLUDE
    SAMPLE_PERCENT    NUMBER(5,2)   DEFAULT 100.00,   -- For SAMPLE strategy
    INCLUDE_FILTER    VARCHAR(4000),    -- Optional WHERE clause for mandatory inclusions
    IS_ACTIVE         BOOLEAN       DEFAULT TRUE,
    LOADED_BY         VARCHAR(100)  DEFAULT 'MANUAL', -- MANUAL, SCALA_PARSER, INFO_SCHEMA, ACCESS_HISTORY
    NOTES             VARCHAR(4000),
    CREATED_AT        TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UPDATED_AT        TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UNIQUE (SOURCE_DATABASE, SOURCE_SCHEMA, TABLE_NAME)
);
```

### 2.3 COLUMN_INVENTORY — All columns with types and FK flags

```sql
CREATE TABLE DATA_REDUCTION_POC.EDRP_METADATA.COLUMN_INVENTORY (
    COLUMN_ID         NUMBER AUTOINCREMENT PRIMARY KEY,
    SOURCE_DATABASE   VARCHAR(256)  NOT NULL,
    SOURCE_SCHEMA     VARCHAR(256)  NOT NULL,
    TABLE_NAME        VARCHAR(256)  NOT NULL,
    COLUMN_NAME       VARCHAR(256)  NOT NULL,
    DATA_TYPE         VARCHAR(100),
    ORDINAL_POSITION  NUMBER,
    IS_NULLABLE       BOOLEAN       DEFAULT TRUE,
    IS_PRIMARY_KEY    BOOLEAN       DEFAULT FALSE,
    IS_FOREIGN_KEY    BOOLEAN       DEFAULT FALSE,
    FK_REFERENCES     VARCHAR(500),     -- Format: TARGET_TABLE.TARGET_COLUMN
    COLUMN_ROLE       VARCHAR(50),      -- PK, FK, MEASURE, ATTRIBUTE, TIMESTAMP, FLAG
    SENSITIVITY_CLASS VARCHAR(50),      -- PII, PHI, PCI, CONFIDENTIAL, PUBLIC
    DISTINCT_COUNT    NUMBER,
    NULL_PERCENT      NUMBER(5,2),
    LOADED_BY         VARCHAR(100)  DEFAULT 'MANUAL',
    CREATED_AT        TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UNIQUE (SOURCE_DATABASE, SOURCE_SCHEMA, TABLE_NAME, COLUMN_NAME)
);
```

### 2.4 RELATIONSHIP_MAP — The core table (Scala parser populates this)

```sql
CREATE TABLE DATA_REDUCTION_POC.EDRP_METADATA.RELATIONSHIP_MAP (
    RELATIONSHIP_ID     NUMBER AUTOINCREMENT PRIMARY KEY,
    SOURCE_DATABASE     VARCHAR(256) NOT NULL,
    SOURCE_SCHEMA       VARCHAR(256) NOT NULL,
    -- Parent side (the table being referenced)
    PARENT_TABLE        VARCHAR(256) NOT NULL,
    PARENT_COLUMN       VARCHAR(256) NOT NULL,
    -- Child side (the table that holds the FK)
    CHILD_TABLE         VARCHAR(256) NOT NULL,
    CHILD_COLUMN        VARCHAR(256) NOT NULL,
    -- Relationship metadata
    JOIN_TYPE           VARCHAR(50)  DEFAULT 'INNER',    -- INNER, LEFT, RIGHT, FULL, CROSS
    CARDINALITY         VARCHAR(20)  DEFAULT '1:N',      -- 1:1, 1:N, N:M
    IS_DECLARED_FK      BOOLEAN      DEFAULT FALSE,      -- TRUE if from DDL constraints
    IS_ENFORCED         BOOLEAN      DEFAULT FALSE,      -- TRUE if Snowflake enforces it
    CONFIDENCE          VARCHAR(20)  DEFAULT 'HIGH',     -- HIGH, MEDIUM, LOW
    RELATIONSHIP_STATUS VARCHAR(20)  DEFAULT 'ACTIVE',   -- ACTIVE, INACTIVE, PENDING_REVIEW
    -- Traceability
    DISCOVERED_BY       VARCHAR(100) NOT NULL DEFAULT 'MANUAL',  -- SCALA_PARSER, INFO_SCHEMA, ACCESS_HISTORY, CORTEX_AI, MANUAL
    DISCOVERY_SOURCE    VARCHAR(500),    -- e.g., repo/file/line for Scala, query_id for ACCESS_HISTORY
    REVIEWED_BY         VARCHAR(100),    -- Who approved this relationship
    REVIEWED_AT         TIMESTAMP_NTZ,
    NOTES               VARCHAR(4000),
    CREATED_AT          TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UPDATED_AT          TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UNIQUE (SOURCE_DATABASE, SOURCE_SCHEMA, PARENT_TABLE, PARENT_COLUMN, CHILD_TABLE, CHILD_COLUMN)
);
```

```sql
    CREATED_BY         VARCHAR(100),
    APPROVED_BY        VARCHAR(100),
    CREATED_AT         TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    UPDATED_AT         TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP()
);
```

## 3. Populate Metadata from INFORMATION_SCHEMA

### 3.1 Populate TABLE_INVENTORY

```sql
INSERT INTO DATA_REDUCTION_POC.EDRP_METADATA.TABLE_INVENTORY 
    (SOURCE_DATABASE, SOURCE_SCHEMA, TABLE_NAME, TABLE_TYPE, TABLE_ROLE, ROW_COUNT, SIZE_BYTES, 
     PRIMARY_KEY_COLS, REDUCTION_STRATEGY, SAMPLE_PERCENT, LOADED_BY)
SELECT 
    'DATA_REDUCTION_POC',
    'STAGE_DATA',
    T.TABLE_NAME,
    CASE 
        WHEN T.TABLE_NAME IN ('CATALOG_RETURNS','STORE_RETURNS','WEB_RETURNS','INVENTORY') THEN 'FACT'
        WHEN T.TABLE_NAME IN ('DATE_DIM','TIME_DIM','CUSTOMER_DEMOGRAPHICS','HOUSEHOLD_DEMOGRAPHICS','INCOME_BAND') THEN 'DIMENSION'
        WHEN T.TABLE_NAME IN ('CUSTOMER','CUSTOMER_ADDRESS','ITEM','STORE','WAREHOUSE','CALL_CENTER',
                               'CATALOG_PAGE','PROMOTION','REASON','SHIP_MODE','WEB_PAGE','WEB_SITE') THEN 'DIMENSION'
        ELSE 'UNKNOWN'
    END,
    CASE 
        WHEN T.TABLE_NAME IN ('CATALOG_RETURNS','STORE_RETURNS','WEB_RETURNS','INVENTORY') THEN 'LEAF'
        WHEN T.TABLE_NAME IN ('INCOME_BAND') THEN 'ROOT'
        WHEN T.TABLE_NAME IN ('DATE_DIM','TIME_DIM','CUSTOMER_DEMOGRAPHICS','SHIP_MODE','REASON',
                               'WAREHOUSE','CALL_CENTER','WEB_SITE','CATALOG_PAGE','WEB_PAGE','PROMOTION') THEN 'ROOT'
        WHEN T.TABLE_NAME IN ('CUSTOMER','CUSTOMER_ADDRESS','HOUSEHOLD_DEMOGRAPHICS','ITEM','STORE') THEN 'INTERMEDIATE'
        ELSE 'UNKNOWN'
    END,
    T.ROW_COUNT,
    T.BYTES,
    -- Primary key columns (TPC-DS convention: *_SK is surrogate key)
    CASE 
        WHEN T.TABLE_NAME = 'CALL_CENTER' THEN 'CC_CALL_CENTER_SK'
        WHEN T.TABLE_NAME = 'CATALOG_PAGE' THEN 'CP_CATALOG_PAGE_SK'
        WHEN T.TABLE_NAME = 'CATALOG_RETURNS' THEN 'CR_ITEM_SK,CR_ORDER_NUMBER'
        WHEN T.TABLE_NAME = 'CUSTOMER' THEN 'C_CUSTOMER_SK'
        WHEN T.TABLE_NAME = 'CUSTOMER_ADDRESS' THEN 'CA_ADDRESS_SK'
        WHEN T.TABLE_NAME = 'CUSTOMER_DEMOGRAPHICS' THEN 'CD_DEMO_SK'
        WHEN T.TABLE_NAME = 'DATE_DIM' THEN 'D_DATE_SK'
        WHEN T.TABLE_NAME = 'HOUSEHOLD_DEMOGRAPHICS' THEN 'HD_DEMO_SK'
        WHEN T.TABLE_NAME = 'INCOME_BAND' THEN 'IB_INCOME_BAND_SK'
        WHEN T.TABLE_NAME = 'INVENTORY' THEN 'INV_DATE_SK,INV_ITEM_SK,INV_WAREHOUSE_SK'
        WHEN T.TABLE_NAME = 'ITEM' THEN 'I_ITEM_SK'
        WHEN T.TABLE_NAME = 'PROMOTION' THEN 'P_PROMO_SK'
        WHEN T.TABLE_NAME = 'REASON' THEN 'R_REASON_SK'
        WHEN T.TABLE_NAME = 'SHIP_MODE' THEN 'SM_SHIP_MODE_SK'
        WHEN T.TABLE_NAME = 'STORE' THEN 'S_STORE_SK'
        WHEN T.TABLE_NAME = 'STORE_RETURNS' THEN 'SR_ITEM_SK,SR_TICKET_NUMBER'
        WHEN T.TABLE_NAME = 'TIME_DIM' THEN 'T_TIME_SK'
        WHEN T.TABLE_NAME = 'WAREHOUSE' THEN 'W_WAREHOUSE_SK'
        WHEN T.TABLE_NAME = 'WEB_PAGE' THEN 'WP_WEB_PAGE_SK'
        WHEN T.TABLE_NAME = 'WEB_RETURNS' THEN 'WR_ITEM_SK,WR_ORDER_NUMBER'
        WHEN T.TABLE_NAME = 'WEB_SITE' THEN 'WEB_SITE_SK'
    END,
    -- Reduction strategy
    CASE 
        WHEN T.TABLE_NAME IN ('CATALOG_RETURNS','STORE_RETURNS','WEB_RETURNS','INVENTORY') THEN 'FK_CASCADE'
        WHEN T.ROW_COUNT < 1000000 THEN 'FULL_COPY'
        ELSE 'SAMPLE'
    END,
    -- Sample percent
    CASE 
        WHEN T.TABLE_NAME IN ('CATALOG_RETURNS','STORE_RETURNS','WEB_RETURNS','INVENTORY') THEN 100.00
        WHEN T.ROW_COUNT < 1000000 THEN 100.00
        WHEN T.TABLE_NAME = 'CUSTOMER' THEN 10.00
        WHEN T.TABLE_NAME = 'CUSTOMER_ADDRESS' THEN 100.00
        ELSE 100.00
    END,
    'INFO_SCHEMA'
FROM DATA_REDUCTION_POC.INFORMATION_SCHEMA.TABLES T
WHERE T.TABLE_SCHEMA = 'STAGE_DATA' AND T.TABLE_TYPE = 'BASE TABLE';
```

## 15. Metadata Table Reference (For Scala Parser Integration)

### How to Populate RELATIONSHIP_MAP from Your Scala Parser

Your Scala parser should output rows in this format and INSERT them into `EDRP_METADATA.RELATIONSHIP_MAP`:

```
SOURCE_DATABASE  | SOURCE_SCHEMA | PARENT_TABLE | PARENT_COLUMN   | CHILD_TABLE     | CHILD_COLUMN              | JOIN_TYPE | CARDINALITY | DISCOVERED_BY | DISCOVERY_SOURCE
DATA_REDUCTION_POC | STAGE_DATA  | CUSTOMER     | C_CUSTOMER_SK   | STORE_RETURNS   | SR_CUSTOMER_SK            | LEFT      | 1:N         | SCALA_PARSER  | repo/etl/store_returns.scala:23
DATA_REDUCTION_POC | STAGE_DATA  | ITEM         | I_ITEM_SK       | CATALOG_RETURNS | CR_ITEM_SK                | INNER     | 1:N         | SCALA_PARSER  | repo/etl/catalog_returns.scala:17
```

### DISCOVERED_BY Values

| Value | When to Use |
|-------|-------------|
| `SCALA_PARSER` | Relationship extracted automatically from Scala/Spark code |
| `INFO_SCHEMA` | Relationship found in Snowflake INFORMATION_SCHEMA constraints |
| `ACCESS_HISTORY` | Relationship discovered from Snowflake ACCESS_HISTORY join patterns |
| `CORTEX_AI` | Relationship suggested by Snowflake Cortex AI analysis |
| `MANUAL` | Relationship added manually by business SME or developer |

### TABLE_INVENTORY Reduction Strategies

| Strategy | When to Use |
|----------|-------------|
| `FULL_COPY` | Small dimension/reference tables — copy all rows |
| `SAMPLE` | Key driver tables (e.g., CUSTOMER) — Bernoulli sample at configured % |
| `FK_CASCADE` | Child/fact tables — only keep rows where FK exists in reduced parent |
| `EXCLUDE` | Tables to skip entirely |
